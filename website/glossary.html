Glossary

Website terms, plainly explained.

Short, plain definitions of the words that come up when you plan, design, build or move a website.

Sections

PlatformsSEO and migrationsDesignPricing and process

Platforms

Webflow

A visual website builder with built-in hosting and a CMS. Designers build real HTML and CSS without writing code, and marketing teams edit content without a developer. Best for content-rich marketing sites. Read more

Framer

A website builder that works like a design tool. It is fast for launch sites and motion-rich pages, with a simpler CMS than Webflow. Read more

WordPress

An open-source content management system that runs about two in five websites. Very flexible through themes and plugins, but hosting, updates and security are the owner's job. Read more

CMS (content management system)

The part of a website where content lives as structured items, such as blog posts, case studies or team members, so editors can add pages without touching the design.

Headless CMS

A CMS that stores content only and sends it to a separately built front end through an API. Flexible for large products, but it needs developers for most changes.

No-code website

A website built in a visual tool like Webflow or Framer instead of hand-written code. It is still real, fast, indexable HTML, and the team can edit it without developers.

SEO and migrations

Website migration

Moving a website from one platform to another, for example from WordPress to Webflow, while keeping content, URLs, links and search rankings. Read more

301 redirect

A permanent redirect from an old URL to a new one. It passes most of the old page's ranking power to the new page, which is why every changed URL needs one after a migration. Read more

Redirect map

A list that pairs every old URL with its closest new URL. It is the single most important document in a migration that keeps traffic. Read more

Core Web Vitals

Google's three page-experience metrics, measured on real visitors: LCP (how fast the main content shows, good under 2.5 s), INP (how fast the page reacts to taps and clicks, good under 200 ms) and CLS (how much the layout jumps, good under 0.1).

Structured data (schema)

Hidden code that tells search engines and AI assistants exactly what a page is about: a company, a service, an article, an FAQ or a price. It helps pages earn rich results and get cited.

AEO (answer engine optimisation)

Writing and structuring pages so AI assistants like ChatGPT, Claude and Perplexity can understand, quote and recommend them. Clear answers, definitions, comparisons and structured data matter most.

llms.txt

A plain text file at the root of a website that summarises who the business is and links to its key pages, written for AI assistants to read.

Canonical URL

A tag that tells search engines which version of a page is the main one, so duplicates do not compete with each other in results.

Design

UI/UX design

UX design decides how a website or product works: structure, flows and what the user needs at each step. UI design decides how it looks: layout, type, colour and components. Read more

Design system

A shared set of components, styles and rules, kept in Figma and in code, so every new page or screen looks consistent and is quick to build. Read more

Figma

The browser-based design tool most teams use to design websites and apps, share them for feedback and hand them to developers.

Wireframe

A simple, grey layout of a page that shows structure and content order before visual design starts.

Landing page

A single page built for one goal, usually sign-ups or enquiries from ads or a launch. It has one message and one main action. Read more

CRO (conversion rate optimisation)

Improving a website so more visitors take the action you want, by testing headlines, layouts, forms and offers against real data. Read more

Brand identity

The visual system of a company: logo, colours, typography, imagery and the rules for using them across the website and materials. Read more

Pricing and process

Fixed-price project

A project with scope, timeline and price agreed in writing before work starts, so the cost does not change unless the scope does. Read more

Design retainer

A monthly plan for ongoing design and development work, with tasks taken from a shared backlog instead of quoted one by one. Read more

UX audit

A review of a website or product against usability and conversion best practice, ending in a ranked list of fixes. Read more

Discovery

The first step of a project, where goals, audience, content and technical needs are collected so the scope and price are accurate. Read more
